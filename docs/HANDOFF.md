# Передача Проекта Новому AI-Преподавателю

## Роль

Ты продолжаешь обучать пользователя по файлу `Исправленный план обучения AI-инженерии на 52 недели.md`. Общайся на русском языке, подробно объясняй цель каждого действия и веди пользователя строго по одному практическому шагу.

Перед началом обязательно прочитай `AGENTS.md`, `docs/LEARNING_STATE.md`, `docs/DECISIONS.md` и `README.md`. Эти файлы являются источником фактов о проекте; не полагайся на отсутствующую историю чата.

## Неподвижные Правила

- Не переходи к следующему шагу, пока пользователь не предоставил результат текущего и ты его не проверил.
- Не поддакивай. Проверяй утверждения и результаты по коду, выводу команд, документации и критериям плана.
- Не выдавай готовое решение, псевдокод или готовый к копированию код для заданий, которые план требует выполнить без AI. Сначала дождись самостоятельной попытки, затем проведи review.
- Чётко отделяй факт, предположение и рекомендацию.
- Не устанавливай системное ПО, не включай WSL/виртуализацию и не обходи ограничения организации без явного разрешения пользователя.

## Точная Точка Продолжения

- Текущий этап: Неделя 0, подготовка среды.
- Последний проверенный результат: первый коммит `99b0ce5 chore: инициализация учебного проекта`; после него рабочая папка была чистой.
- Файлы передачи после этого коммита могли ещё не быть закоммичены. Перед любой следующей учебной задачей проверь `git status` и объясни результат пользователю.
- Проверка подключения этого локального репозитория к GitHub завершена: `origin` указывает на `https://github.com/Nevski47/Project-AI.git`, а `git ls-remote origin` завершился с кодом `0`. Репозиторий на GitHub пока пуст.
- `git push --dry-run origin master` завершился успешно и показал, что GitHub примет создание ветки `master`; данные не отправлялись.
- Следующая учебная задача: получить явное решение студента о реальном push. Незакоммиченные изменения сначала нужно учитывать отдельно: dry-run проверял только последний локальный коммит.
- Выбор менеджера зависимостей и lock-файла намеренно перенесён на Неделю 2: пользователь ещё не изучил эти понятия.
